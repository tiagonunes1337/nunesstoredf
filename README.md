# NunesStoreDF

Site institucional da **Nunes Store DF**, loja de hardware e desenvolvimento web localizada em Brasília - DF.

## Sobre o projeto

Site criado do zero para apresentar os produtos e serviços oferecidos, com foco em conversão via WhatsApp e redes sociais.

## Tecnologias utilizadas

- HTML5
- CSS3
- [Bootstrap 5.3](https://getbootstrap.com/)
- [Bootstrap Icons 1.11](https://icons.getbootstrap.com/)

## Estrutura de arquivos

```
/
├── index.html
├── style.css
└── img/
    ├── placamaeimagem.png
    ├── iphone.jpg
    ├── macbook.png
    ├── criacao-site.png
    └── computador-home-office.png
```

## Funcionalidades

- Hero section com imagem de fundo e overlay
- Seção de produtos com cards (iPhone, MacBook, Desenvolvimento Web, Workstations)
- Seção de contato com botões para WhatsApp, Instagram e Facebook
- SEO básico com meta tags (description, keywords, robots, author)
- Layout responsivo via Bootstrap

## Como rodar localmente

Basta abrir o arquivo `index.html` diretamente no navegador. Não há dependências de servidor ou build.
